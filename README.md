# Side Control

**Your side hustle, under control.** A concept product: a private-lesson book for BJJ coaches, with a working demo built into the landing page.

- Live page: https://kellyjason82.github.io/side-control/
- Coach view: open times, bookings, per-student rates, paid/unpaid, technique notes.
- Student view ("Next Stripe"): open slots, book with the price shown up front, confirm the day before, technique log.

## Run it

Plain HTML, CSS and JavaScript, with no build step. Open `index.html` in a browser, or visit the live page.

The demo runs on invented sample data and saves only in your own browser (localStorage). Nothing is sent anywhere.

Side Control is a concept product in development. The coach, academy, students, prices and bookings shown are invented sample data.
